[h1]Achievement Tracker / 成就条件追踪器[/h1]

Track the requirements behind Isaac achievements directly in-game instead of constantly checking a wiki. The HUD shows concrete conditions, route steps, counters, and warnings, while the F3 menu lets you browse and track up to three goals.

在游戏内直接查看成就的具体完成条件、路线步骤、计数进度与临界提醒，无需频繁切出游戏查询 Wiki。F3 菜单可浏览全部目标，并同时追踪最多三个成就。

[list]

[*]Context-aware route alternatives for relevant items, cards, trinkets, transformations, and multiplayer characters.
[*]Chinese and English interfaces with a bundled Chinese bitmap font; no EID or language resource pack required.
[*]Persistent settings and confirmed completion evidence are separated by Isaac save slot.
[*]Optional integration with Mod Config Menu Pure and REPENTOGON.
[/list]

[list]
[*]HUD 持续显示具体成就条件、进度、路线步骤与失败警告。
[*]F3 可打开可视化目标菜单，支持键鼠操作、分类筛选和中英双语模糊搜索。
[*]覆盖主线、支线、Mother、祸兽、贪婪模式、Boss Rush、死寂、精神错乱、超级撒但和堕化角色解锁路线。

[h1]Import Existing Achievement Progress / 导入现有成就进度[/h1]

The standard Lua API cannot reliably read every vanilla achievement. Windows users can completely close the game and run [b]一键导入成就.cmd[/b] from the mod folder. The local importer reads supported Isaac backup saves, validates all files, backs up existing mod data, and never modifies the original game save.

原版 Lua API 无法可靠读取全部原版成就。Windows 用户可完全关闭游戏，然后运行 Mod 根目录中的 [b]一键导入成就.cmd[/b]。导入器只在本机读取受支持的以撒备份存档，写入前会完成验证并备份已有 Mod 数据，不会修改游戏原始存档。

[h1]Known Limitations / 已知限制[/h1]

Without an imported snapshot or REPENTOGON, some achievements and old completion marks may remain “unconfirmed.” The tracker deliberately avoids guessing missing progress. Search input accepts English letters, numbers, and spaces, but searches both Chinese and English catalog data.

Native HUD/F3 atlases avoid fractional scaling inside the glyph textures, but the game's global Filter setting, GPU scaling, or display post-processing may still soften the final image. The mod does not override the user's Filter setting.

未导入快照且未安装 REPENTOGON 时，部分成就与旧通关标记可能显示为“未确认”；追踪器不会猜测缺失进度。搜索输入仅接受英文字母、数字和空格，但会同时检索中英文资料。

HUD/F3 原生字库可避免字形纹理内部的分数缩放，但游戏全局 Filter、显卡缩放或显示器后处理仍可能使最终画面变软；本 Mod 不会覆盖用户的 Filter 设置。

[h1]Version 0.7.2[/h1]

Improves text robustness across resolutions. HUD and F3 now share native 11/22/33px fonts drawn at 1:1: LanaPixel uses a hard-edged 11px design grid with exact 2x/3x nearest-neighbor variants, while Chinese fallback glyphs retain antialiasing. F3 grows height-first and then width-first; HUD downgrades at the saved position, shifts left only at the 11px floor, and paginates complete goals on extremely small screens.

改善不同分辨率下的文字显示。HUD 与 F3 共用原生 11/22/33px 字库并按 1:1 绘制：LanaPixel 以 11px 硬边设计栅格为基准，22/33px 为精确 2×/3× 最近邻版本，中文后备字形保留抗锯齿。F3 面板先增高、再加宽；HUD 在保存位置先降档，仅在 11px 仍不足时左移，并在极小画面按完整目标分页。
