Achievement Tracker 存档导入器

所有解析都在此浏览器页面内完成，文件不会上传，也不会修改《以撒》的原始存档。

操作前请关闭游戏并备份文件。下载完成后，再手动替换 Mod 数据目录中的对应 saveN.dat；替换后重新启动游戏。

生成 Mod 存档

可选择 persistentgamedataN.dat、Steam Cloud 的 rep_persistentgamedataN.dat、Repentance+ 的 rep+persistentgamedataN.dat，或它们带日期前缀的备份。

只有文件名无法识别时才需手动选择；若文件名与手选槽位冲突，导入会停止。

选择后会保留原有语言、追踪目标、观察记录和其他设置。不选择则生成最小的新存档。

常见目录

本地游戏存档通常位于 %USERPROFILE%\Documents\My Games\Binding of Isaac Repentance；Steam Cloud 文件通常位于 Steam\userdata\<SteamID>\250900\remote，常见文件名为 rep_persistentgamedataN.dat 或 rep+persistentgamedataN.dat。

Mod 存档位于游戏目录下的 data\achievement_tracker\saveN.dat。请先把旧文件复制到安全位置，再放入下载的新文件。
